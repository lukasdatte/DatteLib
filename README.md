# DatteLib

> **Retired (2026-10-25). This library is no longer maintained and the repository is archived.**
>
> Its last release, 1.0.15 (2022), pins csv-parse 4 and lodash 4.17.21, which carry
> known security advisories. Do not add it to new code. Its former consumers
> (ersatzteil-scraper, jtl_cli, HusqvarnaRegistierung) replaced it with small local
> CSV and directory helpers on csv-parse 7 / csv-stringify 6 and lodash 4.18.1.

See: Wiki (`wiki/`) for the API as it was.
